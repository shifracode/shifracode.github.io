# موقع ShifraCode

> Your dream, coded.

ده موقع **شفرة كود**: صفحة واحدة معمولة بـ HTML و CSS و JavaScript من غير أي مكتبات، علشان تقدر تفهم كل سطر فيه وتعدّل عليه بنفسك.

## الملفات

الموقع بلغتين: بيفتح **إنجليزي**، وفي الهيدر زرار "عربي" بيودّي للنسخة العربي، وزرار "English" في العربي بيرجّع للإنجليزي.

| الملف | فيه إيه |
|---|---|
| `index.html` | **الصفحة الإنجليزي** (الرئيسية): الكلام والأقسام والزراير |
| `ar/index.html` | **الصفحة العربي**: نفس الأقسام بالعربي |
| `style.css` | **الشكل**: الألوان والخطوط والمسافات |
| `script.js` | **الحركة**: زرار الواتساب والكود اللي بينزل في الخلفية |
| `assets/logo.svg` | اللوجو |
| `assets/share.png` | الصورة اللي بتظهر لما حد يبعت لينك الموقع على واتساب أو فيسبوك |

## أرقام الواتساب

الأرقام موجودة في أول `script.js`، بالكود الدولي ومن غير `+` ومن غير الصفر اللي في الأول:

```js
const WHATSAPP_NUMBERS = {
  eg: "201118308203", // مصر
  ae: "971525470063", // الإمارات
};
const WHATSAPP_DEFAULT = "ae";
```

- زراير "كلمنا واتساب" و"ابدأ مشروعك" بتستخدم الرقم اللي في `WHATSAPP_DEFAULT`، ودلوقتي هو رقم الإمارات
- في قسم التواصل فيه زرارين: الإمارات (الأساسي) ومصر
- لو عايز الرقم الأساسي يرجع لمصر، غيّر `"ae"` لـ `"eg"`

## إزاي تشوف الموقع على جهازك

دبل كليك على `index.html`، وهيفتح في المتصفح.

## إزاي تعدّل

- **الكلام:** الإنجليزي في `index.html` والعربي في `ar/index.html`. **أي تعديل في صفحة، اعمله في التانية كمان** علشان النسختين يفضلوا زي بعض
- **رسالة الواتساب الجاهزة:** في `script.js` تحت `WHATSAPP_MESSAGES`، فيها رسالة لكل لغة
- **الألوان:** افتح `style.css`، كل الألوان في أول الملف تحت `:root`
- **إضافة خدمة:** في `index.html` انسخ أي `<article class="card">` كامل لحد `</article>`، وغيّر الكلام اللي جواه

## مهم بعد أي تعديل في `style.css` أو `script.js`
غيّر رقم النسخة في الصفحتين (`index.html` و `ar/index.html`)، مثلًا من `style.css?v=6` لـ `style.css?v=7`.
ده بيخلي المتصفح يحمّل النسخة الجديدة بدل النسخة القديمة المحفوظة عنده.

## إزاي ترفعه أونلاين ببلاش (GitHub Pages)

1. ادخل على [github.com](https://github.com) بحساب `shifracode`
2. اعمل Repository جديد اسمه **`shifracode.github.io`** بالظبط، وخليه **Public**
3. دوس **Add file ← Upload files**، واسحب كل الملفات والفولدرات اللي هنا (`index.html` و `style.css` و `script.js` وفولدر `ar` وفولدر `assets`)
4. دوس **Commit changes**
5. استنى دقيقة أو اتنين، وافتح: **https://shifracode.github.io**

بعد كده، أي تعديل ترفعه بنفس الطريقة، والموقع هيتحدث لوحده.

> لو اسم الحساب على GitHub طلع مختلف (زي `shifracode-studio`)، يبقى اسم الـ Repository لازم يبقى `shifracode-studio.github.io`.

## لما تشتري دومين

لما تشتري `shifracode.dev` مثلًا، ادخل على إعدادات الـ Repository، وبعدين **Pages ← Custom domain**، واكتب الدومين. وهتلاقي هناك الخطوات اللي هتعملها عند الشركة اللي اشتريت منها.
